# راهنمای ادغام امن با مخزن موجود

1. فایل مادر را با نام `docs/implementation/MASTER-EXECUTION-PLAN-10000-LINES.fa.md` اضافه کنید.
2. از overwrite کردن `ROADMAP.fa.md`، `README.fa.md` یا `AGENTS.md` فعلی خودداری کنید؛ ابتدا تفاوت‌ها را ثبت کنید.
3. به README موجود یک بخش «Execution plan» اضافه کنید که به فایل جدید لینک بدهد.
4. از فایل CSV، issue بسازید؛ statusها باید TODO باقی بمانند تا agent شواهد انجام‌شدن ارائه کند.
5. مسیرهای inventory را در checkout واقعی با Next.js App Router تطبیق دهید و مواردی که tab داخلی‌اند مشخص کنید.
6. هیچ deploy/push انجام ندهید مگر مالک مخزن صریحاً تأیید کند.
7. در اولین PR فقط اسناد، backlog و validator را اضافه کنید؛ بعد از review، فاز P00 را جداگانه آغاز کنید.
