# License و reuse policy

این بسته reference repoها را به‌عنوان منبع مطالعه معرفی می‌کند، نه مجوز copy/paste. قبل از port کردن کد یا asset:

1. LICENSE در root و هر subdirectory مربوطه را در همان tag/commit بررسی کن.
2. فایل بدون LICENSE صریح را مجاز به کپی فرض نکن.
3. برای AGPL/GPL، network use/distribution/derivative implications را با مسئول حقوقی بررسی کن.
4. کد/asset/trademark/logo/فونت/تصویر و screenshot هرکدام حقوق جدا می‌توانند داشته باشند.
5. dependency provenance، version، license، notice، تغییرات و attribution را ثبت کن.
6. security advisories، maintenance status، dependency tree و license transitive بررسی شود.
7. اگر مجوز unclear است، فقط behavior/interaction را مشاهده و implementation مستقل انجام بده.
8. قبل از production، SBOM و policy اتوماتیک برای dependency license/known vulnerability تعریف کن.

این متن مشاوره حقوقی نیست؛ تیم مسئول باید interpretation مجوزها را تأیید کند.
