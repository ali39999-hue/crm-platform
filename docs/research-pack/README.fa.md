# بسته تحقیق و رودمپ CRM Platform

این بسته برای مخزن [ali39999-hue/crm-platform](https://github.com/ali39999-hue/crm-platform) است.

## فایل‌ها
- `CRM_PLATFORM_RESEARCH_ROADMAP.fa.md`: نقشه اصلی، معماری، flowها، UI/UX، فازبندی و سیاست استفاده از کد.
- `REPOSITORY_CATALOG.csv`: 164 مخزن دسته‌بندی‌شده با کاربرد، اقدام توصیه‌شده، اولویت و یادداشت license review.
- `PHASE_BACKLOG.csv`: تسک‌های قابل انتقال به Jira/Plane/Linear؛ هر مورد دارای ID، owner پیشنهادی، priority و acceptance criteria است.
- `UI_UX_AUDIT_CHECKLIST.csv`: چک‌لیست قابل استفاده در review و QA.

## مهم
- «کاتالوگ curated» است، نه همه repositoryهای موجود در اینترنت.
- پیش از هر fork/copy/dependency، مجوز، status، security advisories، release و transitive dependencies را در منبع رسمی بررسی کنید.
- `P0` یعنی blocker برای مسیر اصلی یا ریسک جدی؛ `P1` مهم برای MVP؛ `P2` آینده/گزینه اختیاری.
- زمان‌های فازبندی تخمینی‌اند و باید با ظرفیت تیم اصلاح شوند.
- این بسته روی GitHub push نشده است.
